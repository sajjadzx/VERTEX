## ۱. معرفی پروژه (Project Overview)

پروژه **VERTEX** یک پلتفرم وبسایت شوکیس مهندسی مدرن در سبک **Industrial Luxury & Futuristic Minimalism** است که برای نمایش توانمندی‌های بین‌المللی طراحی وب و تخصص در صنعت ترابری عمودی (آسانسورهای کششی پرسرعت، بالابرهای بدون موتورخانه MRL، پله‌برقی‌های سنگین‌کار شهری و پیاده‌روهای متحرک) طراحی و پیاده‌سازی شده است.

- **نام برند:** VERTEX
- **شعار محوری:** Moving Beyond Limits (حرکت فراتر از مرزها)
- **شعار مهندسی:** Engineering Vertical Mobility (مهندسی جابجایی عمودی)
- **سیستم رنگی برند:**
  - **Midnight Navy:** `#101923`
  - **Technology Cyan:** `#00C2B8`
  - **Steel Gray:** `#A9B7C4`
  - **Ice White:** `#F4F7FA`
- **تایپوگرافی:**
  - انگلیسی: **Inter** (طراحی خطی و ردیابی عریض حروفی صنعتی)
  - فارسی: **Vazirmatn** (اعراب‌گذاری دقیق، انطباق کامل با دایرکشن RTL)

## ۲. ساختار صفحات ۹ گانه (Website Architecture)

وبسایت به صورت متقارن در دو زبان انگلیسی (`/en`) و فارسی (`/fa`) شامل ۹ مسیر اختصاصی زیر است:

1. **صفحه اصلی (`/`)**: هیرو سینمایی، آمار کلیدی صنعتی (۱۲.۵ متر بر ثانیه، ۹۹.۹۸٪ آپ‌تایم، ۳۵٪ بازیابی انرژی)، معرفی ۳ ستون ترابری، پیش‌نمایش ماژول‌های تعاملی و فراخوان استعلام مهندسی.
2. **راهکارهای آسانسور (`/elevators`)**: تفکیک مدل‌های High-Rise Skyscraper، MRL لوکس شهری، Panoramic شیشه‌ای آتریوم، Heavy Freight صنعتی، به همراه ماتریس مشخصات فنی و جدول مقایسه‌ای سرعت و ظرفیت.
3. **سامانه‌های پله‌برقی (`/escalators`)**: پله‌برقی‌های سنگین‌کار مترویی و فرودگاهی (EN 115-1/2)، تجاری لوکس، پیاده‌روهای متحرک افقی و شیب‌دار (Autowalks)، به همراه تشریح سیستم هوشمند توقف کم‌مصرف Eco-Crawl.
4. **پیکربندی هوشمند کابین (`/configurator`)**: استودیوی تعاملی شخصی‌سازی متریال دیواره‌ها (تیتانیوم دودی، شیشه ابسیدین، استیل برنز، فیبرکربن)، پوشش کف (مرمر ایتالیایی، گرانیت، استیل آجدار)، سقف‌های نوری، دمای رنگ و پنل‌های شستی (COP) با پیش‌نمایش رندر زنده.
5. **فناوری و مهندسی پیشرفته (`/engineering`)**: الگوریتم تخصیص هوشمند مقصد VERTEX Flow™، موتورهای گیرلس PMSM، سیستم بازیافت توان الکتریکی به شبکه ساختمان و استانداردهای شتاب‌سنجی ارتعاشات طبق ISO 18738.
6. **پروژه‌ها و نمونه‌کارها (`/projects`)**: پورتفولیوی پروژه‌های بین‌المللی برج‌های آسمان‌خراش، پایانه‌های فرودگاهی و هتل‌های لوکس (با نشانه‌گذاری صریح شبیه‌سازی/دمو).
7. **نگهداری هوشمند و IoT (`/maintenance`)**: معرفی سطوح خدمات ۲۴/۷، اعزام کمتر از ۲۵ دقیقه، و داشبورد تلمتری آنلاین با شبیه‌ساز پینگ سنسورها.
8. **درباره ورتکس (`/about`)**: پیشینه شرکت از سال ۱۹۹۸، فلسفه مهندسی ایمنی مطلق، برج آزمایش ۲۴۵ متری با ۷ چاهک تست سرعت بالا و مدارک ISO 9001، ISO 14001 و دایرکتیو اتحادیه اروپا.
9. **مشاوره و تماس (`/contact`)**: ویزارد چندمرحله‌ای برآورد اولیه مشخصات آسانسور (Smart Consultation Wizard)، فرم دریافت دوسیه فنی و اطلاعات دفاتر زوریخ، دبی و تهران.

## ۳. ماژول‌های تعاملی تخصصی (Interactive Engineering Features)

### الف) Cabin Configurator (پیکربندی سه‌بعدی و زنده کابین)
- انتخاب لحظه‌ای از میان ۴ متریال پیشرفته دیواره با شبیه‌سازی بافت، انعکاس نور و پنل آینه‌ای.
- ۴ نوع سنگ و پوشش کف با محاسبه اضافه وزن مرده بر حسب kg/m².
- ۳ سبک سقف (خطی لوور، کهکشانی فیبرنوری، نور مخفی هالو) با قابلیت تغییر دمای نور (۳۰۰۰، ۴۰۰۰ و ۵۰۰۰ کلوین).
- پنل شستی (COP) لمسی تمام شیشه و دکمه‌ای برجسته با نمایشگر دیجیتال طبقات.
- دکمه استخراج و کپی برگ مشخصات فنی جهت ارائه به واحد طراحی معماری.

### ب) Elevator Anatomy (کالبدشکافی تعاملی آسانسور کششی)
- شماتیک فنی منفجرشده قطعات درون چاهک و موتورخانه.
- قابلیت انتخاب موتور سنکرون PMSM، گاورنر سرعت دوطرفه، سیم‌بکسل‌های پرمقاومت، یوک کابین، وزنه‌تعادل، ترمز پاراشوت تدریجی، ریل‌های هادی T شکل و ضربه‌گیرهای هیدرولیک چاهک.
- ارائه استانداردهای فنی EN 81-20 و تشریح تفاوت ساختارهای کششی با سیستم‌های بدون موتورخانه (MRL).

### ج) Escalator Explorer (کاوشگر برش عرضی پله‌برقی)
- شماتیک مقطع عرضی خرپای سازه‌ای، استپ‌های آلومینیومی دایکست، واحد محرک خورشیدی، هندریل با استریل‌کننده UV-C و صفحات شانه (Comb Plates).
- توضیح سنسورهای ایمنی هوشمند طبق EN 115-1.

### د) Maintenance Telemetry Dashboard (داشبورد شبیه‌ساز نگهداری)
- جدول پایش وضعیت سنسورهای دما، ارتعاش یاتاقان، شمارنده سیکل‌های حرکتی و فرسایش کابل.
- قابلیت ارسال پینگ دیاگ شبیه‌سازی‌شده سنسورها و مشاهده لاگ بلادرنگ.
- **دارای برچسب و سلب مسئولیت رسمی دمو و شبیه‌سازی داده‌ها.**

### ه) Smart Consultation Wizard (ویزارد تخمین اولیه بالابر)
- فرآیند ۳ مرحله‌ای جمع‌آوری کاربری ساختمان، تعداد طبقات، ارتفاع کل، ابعاد چاه و ترافیک ساعات اوج.
- موتور محاسباتی تخمین سرعت نامی (m/s)، ظرفیت مسافر (kg / نفر) و نوع سیستم محرک.
- **همراه با اخطار مهندسی مشروط بودن نتایج به نقشه‌های محاسباتی رسمی مهندسین آسانسور.**

## ۴. معماری دوزبانه و سئو (Bilingual & SEO Architecture)

- پشتیبانی کامل از دو دایرکشن **LTR** (انگلیسی) و **RTL** (فارسی).
- تغییر زبان بدون تغییر صفحه کاربر (Preserving Current Route).
- ایجاد متادیتای اختصاصی سئو، OpenGraph و تگ‌های جایگزین (Alternates / hreflang) برای هر دو زبان.
- ایجاد خودکار `sitemap.xml` و `robots.txt` در روت پروداکشن.
- انطباق با اصول دسترسی‌پذیری وب (A11y)، دکمه‌های فوکوس‌پذیر و تضاد رنگی بهینه بر اساس وب کنتراست WCAG.

## ۵. راهنمای اجرا و استقرار (Installation & Execution)

### نیازمندی‌ها:
- Node.js 18+ یا 20+ یا 24+
- npm 9+

### مراحل راه‌اندازی:
```bash
# نصب پکیج‌ها
npm install

# اجرای محیط توسعه (Development Server)
npm run dev
# دسترسی در مرورگر: http://localhost:3000

# ساخت نسخه پروداکشن (Production Build)
npm run build

# اجرای سرور پروداکشن
npm run start
```

1. کلیه پروژه‌ها و داده‌های تلمتری با برچسب مشخص نمایشی (Showcase & Demo) ثبت شده‌اند.
2. هیچ ادعای کذبی مبنی بر ارتباط به تجهیزات صنعتی فیزیکی واقعی یا محاسبه دارای گواهی بازرسی رسمی نشده است.
3. تمامی دکمه‌ها و لینک‌های ۹ گانه فعال و با عملکرد کامل پیاده‌سازی شده‌اند.
4. پروژه در هر دو زبان و تمامی ابعاد صفحه‌نمایش (موبایل، تبلت و دسکتاپ) کاملاً واکنش‌گرا و بهینه تست گردیده است.
